velog 대신 GitHub Pages + Jekyll(Chirpy 테마)로 새 기술 블로그를 시작합니다.

## 이 블로그의 구조

- 글은 `_posts/YYYY-MM-DD-제목.md` 형식의 마크다운 파일로 작성합니다.
- 카테고리와 태그는 각 글의 front matter(`categories`, `tags`)로 지정합니다.
- `main` 브랜치에 push하면 GitHub Actions가 자동으로 빌드하고 배포합니다.

앞으로 개발하며 배운 내용을 꾸준히 기록해보려고 합니다.
